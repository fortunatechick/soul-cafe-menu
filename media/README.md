# Menu item image checklist

Drop a photo for any item below into this folder, then run `npm run sync-media`.
Name each file after the item (spaces / case / punctuation do not matter) — e.g. `Cappuccino.jpg`, `iced-latte.png`.
Supported: .jpg .jpeg .png .webp .avif   ·   Items with no photo simply render text-only.
